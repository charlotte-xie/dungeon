# Long-Term Memory

Memory is the story's notebook: the people, places and things that keep coming back, and what is true about them. Keep it like good notes: short descriptions, full sentences for facts, and a map wherever there is more than one of something. It holds what lasts. The story itself keeps what happened, and the scene of the moment.

```json
{
  "Hesta": {
    "is": "the town baker, owner of the bakery on Mill Lane",
    "appearance": { "build": "stout", "hair": "grey, tied back" },
    "wearing": { "apron": "flour-dusted apron", "dress": "grey wool dress" },
    "wants": {
      "shop": "keep the bakery open",
      "son": "keep her son out of the constabulary's hands"
    },
    "knowledge": {
      "constable": "Hesta saw Amy argue with a constable.",
      "suspect": "Hesta knows the constable is looking for a stranger to blame for last night's robbery."
    },
    "attitude": "Hesta is wary of Amy and helps only when it costs her nothing.",
    "secrets": {
      "tam": "Hesta is hiding her son Tam upstairs after the robbery went wrong; only she and Tam know."
    }
  },
  "Mill Lane": {
    "is": "a crooked street of shops above the river",
    "layout": {
      "bakery": "Hesta's bakery, with rooms above",
      "lockup": "the constabulary lockup at the river end"
    }
  },
  "player": {
    "name": "Amy",
    "is": "a drifter newly arrived in town",
    "wearing": { "coat": "patched army greatcoat" },
    "possessions": { "money": "30 pounds", "sabre": "chipped sabre" },
    "reputation": "Amy is known on Mill Lane as the stranger who argued with the constable."
  }
}
```

The player's character is `player`. Their name comes as it would in any story: from the scenario, from the player introducing themselves, or from someone who knows them. Their wants and feelings are the player's own.

When something changes, write it as it now stands, and let go of what no longer matters. If the story and the notes disagree, the story is right. Older notes may still say `bond` or `oaths`, or file the player's character under their name or `you`: move these to `attitude`, `promises` and `player`.
